# Accessibility audit

WCAG 2.1 AA-focused audit of Frame Studio (static analysis + token contrast
math; a full screen-reader pass across Safari/VoiceOver and NVDA is still
recommended before public release). Last audited: Nov 2026.

## Fixed in this audit

- **Contrast of text on accent/danger buttons failed AA.** White text on the
  dark-mode accent (#5b8bff) was 3.19:1 and on light-mode accent (#3d6ef7)
  4.40:1 — both under the 4.5:1 threshold; danger was worse (2.77:1 in dark).
  Fix: new `--c-on-accent` / `--c-on-danger` tokens (dark near-black text on
  bright fills) and slightly adjusted fills. All accent/danger button text now
  passes AA: accent 6.09:1 (dark) / 4.82:1 (light), danger 5.24:1 (dark) /
  4.73:1 (light).

## Verified compliant (no change needed)

| Area | Status |
| --- | --- |
| Body/secondary text contrast | text-hi 15–17.6:1, text-lo 5.3–5.8:1 — AA ✓ |
| Focus visibility | global `:focus-visible` ring (`--c-ring`) ✓ |
| Reduced motion | `@media (prefers-reduced-motion: reduce)` ✓ |
| Keyboard: timeline | track is `role="slider"` with tabIndex, arrow scrubbing ✓ |
| Keyboard: assets | cards are `role="option"` with tabIndex + Enter/Space ✓ |
| Icon buttons | aria-labels throughout (Delete, Undo, Export, …) ✓ |
| Range inputs | every `<input type="range">` has an aria-label ✓ |
| Text inputs | labeled via aria-label/placeholder+context ✓ |
| Images | all `<img>` have alt text or `alt=""` when decorative ✓ |
| Dialogs | Radix primitives: focus trap, Esc close, aria-labelledby ✓ |
| Live feedback | toasts are `role="status" aria-live="polite"` ✓ |
| Landmarks | `<header>` + `<main>`, single `<h1>` per view ✓ |
| Toggles | `role="switch"` + `aria-checked` ✓ |
| Viewport | `viewport-fit=cover`, touch targets ≥ 24 px in toolbars ✓ |

## Known remaining gaps

- No screen-reader session yet (VoiceOver/NVDA walkthrough recommended).
- Drag-only interactions (timeline trim handles, curve editor knots) have
  keyboard-adjacent alternatives (playhead scrub, +/- via sliders) but not
  direct keyboard dragging.
- Color-picking and histogram work remain visual-only experiences.
